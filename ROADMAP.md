# Roadmap: from frozen lists to living radars

*Executes [VISION.md](./VISION.md). Rule inherited from the movement: content before websites, rhythm before scale.*

## Phase 0: foundation (now)

- [ ] Adopt VISION, this roadmap, and the [radar template](./radars/TEMPLATE.md)
- [ ] Propose radar ownership to the two active chapters: **AI Evolve** (AI radar) and **HR Evolve** (HR-tech radar). Their acceptance is their decision, ideally at the first network council
- [ ] Move the 2018–2021 data (`src/data/`) to `archive/` with a README honoring it as the historical record and the contributors who built it
- [ ] Housekeeping: the repo carries a stray `.git 2` directory (2GB) that needs manual deletion, and the Bower/Grunt toolchain stays untouched until Phase 3

## Phase 1: first living radars (quarter 1)

- [ ] **AI radar v1**: seeded from AI Evolve's recent sessions, in one working meeting with the chapter lead; every entry linked to a session log
- [ ] **HR-tech radar v1**: same pattern with HR Evolve
- [ ] First **Ladder** self-assessments published for both domains
- [ ] Radar update becomes a standing 10-minute segment of each owning chapter's monthly session ("what moved this month"), so curation costs no extra meetings

## Phase 2: prove the rhythm (quarters 2–3)

- [ ] Each active radar ships **revision 2 and 3 on schedule** (quarterly); the "Moves this revision" section is where the value shows
- [ ] **Space and Game radars** seeded as those chapters reach incubating status
- [ ] Ladder linked from μLearn interest groups and Beyond Syllabus career context, so "where do I stand" has one canonical answer per domain
- [ ] First community radar contribution merged from someone outside the chapter committees

## Phase 3: the new face (quarter 4, only if Phase 2 held)

- [ ] Retire the 2018 stack (Foundation/Bower/Grunt/Gulp); replace with a minimal static site generated from the radar markdown, matching the movement's design language
- [ ] Radar history visualized (what moved, over years, per domain), the feature the git history makes free
- [ ] Domains without chapters (blockchain, AR/VR, quantum from the old list) stay archived until a chapter or committed maintainer claims them; honesty over coverage

## Metrics

- Radar revisions shipped on schedule (the only growth that matters)
- Entries with a session-log source (target: all of them)
- People who complete a Ladder self-assessment and take the named next step
- Not metrics: domain count, page views, tool count per radar

## The one-sentence test

If someone asks "what should I learn next in AI, and where do I stand," the answer should be one link. When that is true, Techmyrmidons is back.
